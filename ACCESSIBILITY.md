# Accessibility

SpreadSignal aims to make outbreak intelligence understandable and usable across devices and assistive technologies.

## Commitments

- Use semantic HTML and accessible labels for interactive controls.
- Maintain readable contrast, clear focus states, and keyboard access.
- Keep responsive layouts legible on narrow screens.
- Pair visual status indicators with plain-language text.

## Reporting an accessibility barrier

Open an issue using the bug-report form and describe the task you were trying to complete, the technology you use, and the barrier you encountered. Please do not include sensitive health information.
