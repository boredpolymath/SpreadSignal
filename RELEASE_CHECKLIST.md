- [x] Use an explicit unavailable state instead of fabricated fallback values.
- [x] Keep source, date, reporting-site count, and interpretation limits visible.
- [x] Provide privacy and source documentation.

- [ ] Review all public copy and source links after the production deployment is live.
- [ ] Configure hosting, domain, uptime monitoring, and an incident contact before announcing the public URL.
