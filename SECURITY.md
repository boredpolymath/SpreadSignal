# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please **do not** publish a public issue containing a security vulnerability, credential, or sensitive health information.

Instead, contact a repository maintainer privately through GitHub with:

- a clear description of the issue;
- affected file paths or features;
- reproducible steps or a proof of concept, if safe to share; and
- the potential impact.

Maintainers will acknowledge reports, assess the impact, and coordinate a fix before public disclosure. This prototype should never be used to store identifiable health information or production credentials.
